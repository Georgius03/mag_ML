## Цель работы

Приобретение практических навыков построения нейросетевого классификатора для идентификации типа подстилающей поверхности при движении мобильного робота. Исследование влияния гиперпараметров полносвязной нейронной сети (MLP), предобработки данных (нормализация, балансировка классов) на качество модели. Оценка качества на независимой контрольной выборке.

## Описание набора данных

Исходные данные предоставлены в Excel-файлах:

- `Data_Set_(A+B).xlsx` – обучающая и валидационная выборка (176 образцов)
- `Data_Set_C.xlsx` – тестовая выборка (58 образцов)
- `Data_Set_D.xlsx` – контрольная выборка заказчика

Каждый образец содержит:

- **Показания датчиков** (`V1`): токи двигателей `I1,I2,I3`, угловые скорости `gx,gy,gz`, ускорения `ax,ay,az`, обороты колёс `N1,N2,N3`.
- **Реальные скорости двигателей** `V1real,V2real,V3real` (в работе не использовались).
- **Целевая метка** `Type`: в исходных данных 5 классов (типы поверхностей 1-5).  
    Для задачи бинарной классификации выбран **класс 4** (преобразован в 1, остальные в 0).

На основе исходных переменных рассчитаны производные признаки множеств **V2** и **V3** согласно кинематической модели робота (см. методичку):

- **V2**: линейные скорости робота `vx, vy`, угловая скорость `v_omega`, токовые эквиваленты `curr_x, curr_y, curr_total`.
- **V3**: относительные параметры
$$T_x = \frac{v_x}{curr_x}$$
$$T_{total} = \frac{v_{omega}}{curr_{total}}$$
$$T_{z} = \frac{g_{z}}{curr_{total}}$$

> [!IMPORTANT]  
> В соответствии с вариантом №19 для обучения использовались **только признаки множеств V1 и V3**.  
> Целевая переменная – **бинарный признак "поверхность типа 4"**.

## Предварительная обработка данных

1. **Расчёт кинематических признаков** с помощью класса `RobotKinematicsProcessor`.
    Параметры робота: радиус колеса `R = 0.04 м`, расстояние до колёс `L = 0.125 м`, угол установки колёс `θ = 30°`.
2. **Формирование итогового набора признаков**: `V1_name` (12 переменных) + `V3_name` (4 переменные) → 16 входных признаков.
3. **Масштабирование** данных в диапазон `[0,1]` с помощью `MinMaxScaler` (применялось в соответствующих экспериментах).
4. **Балансировка классов** методом **SMOTE** (только для финальной модели).

> [!NOTE]
> Для анализа распределения признаков и выявления выбросов использовался `ydata-profiling` (результаты сохранены в HTML-отчётах).

## Архитектура нейросети и подход к оптимизации

Использовался многослойный перцептрон `MLPClassifier` из библиотеки `scikit-learn`.

**Варьируемые гиперпараметры:**

- Количество скрытых слоёв (1–3)
- Число нейронов в каждом слое (3–100)
- Функция активации (`logistic`, `tanh`, `relu`)
- Алгоритм обучения (`lbfgs`, `sgd`, `adam`) (в 2 последних экспериментах использован `lbfgs` ввиду лучшего обучения с ним)
- Максимальное число итераций (500–2000)

**Метрики качества:**

- Среднее значение **F1-score** по 5-фолдовой кросс-валидации (максимизация)
- Стандартное отклонение F1-score по фолдам (минимизация для устойчивости моделей)

Для автоматического подбора гиперпараметров применялся фреймворк **Optuna** с многокритериальной оптимизацией гиперпараметров с отображением на (Pareto front).  
Лучшие конфигурации сохранялись в файлы `.pkl` для воспроизводимости.
